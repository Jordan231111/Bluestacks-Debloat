Download **BluestacksDebloat.exe**, then double-click it. Windows 10/11 x64; no Rust installation or separate runtime required.

What's new:

- Native Rust app with a responsive UI and adjustable text size.
- Debloat BlueStacks and remove BlueStacks X/Store and cloud Services independently.
- Dedicated Magisk root tab: install, repair, verify, unroot, and recover.
- Maximum preset keeps CPU/RAM unchanged; rooting remains separate.
- BlueStacks-only network filters, isolated ADB, previews, and verified recovery copies.

Tested on BlueStacks **5.22.265.1013** with Android 9/11/13; the complete fresh-root cycle was tested on Android 11. Automated formatting, Clippy, and **29 tests** pass. [Validation details](https://github.com/Jordan231111/Bluestacks-Debloat/blob/v1.0.0/docs/VALIDATION.md).

This build is unsigned. Root/patching are optional; some games reject root. Recovery copies use disk space, and root recovery restores data to its saved point in time. A 240 FPS limit is not a performance guarantee.

**SHA256SUMS.txt** contains download checksums. The ZIP includes the same executable, documentation, and license notices.
