**Review and Apply are now always visible in a fixed bottom bar.** Review shows pending changes; Apply makes them and reports a verified result.

- Automatically keep the newest **3 verified backups total**, across debloat and root. No retention setting.
- Delete a backup manually or run a full integrity check from Backups & restore.
- Report missing, corrupt, and unfinished recoveries; protect unresolved recovery and resume interrupted deletion.
- Verify all recorded recovery files before restoration. New journals have checksums, and large disks are hashed during copying.

Download **BluestacksDebloat.exe** and replace the old executable. Windows 10/11 x64; no runtime installation required. The ZIP includes documentation and notices; download hashes are in **SHA256SUMS.txt**.

Unfinished or damaged recovery points can temporarily exceed the three-backup limit until resolved. This release is unsigned. BlueStacks validation remains scoped to **5.22.265.1013**; see [validation details](https://github.com/Jordan231111/Bluestacks-Debloat/blob/v1.0.1/docs/VALIDATION.md).
